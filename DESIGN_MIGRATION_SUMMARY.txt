================================================================================
CUSTOMIZATION GUIDE
================================================================================

To customize the design:

1. Colors: Modify CSS variables in App.css :root selector
2. Spacing: Adjust --spacing-* variables
3. Border Radius: Change --border-radius-* values
4. Font: Update --font-family variable
5. Shadows: Modify --shadow-* variables

Example:
  :root {
    --primary-color: #your-color;
    --secondary-color: #your-accent;
    /* etc */
  }
