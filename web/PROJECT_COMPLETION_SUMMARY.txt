## 🏗️ Architecture Overview

### Technology Stack
```
Frontend Framework: React 18 + React Router 6
Animation: Framer Motion 10.16.4
Styling: Tailwind CSS 3.4 + PostCSS
Build Tool: Vite 7.2
State Management: Zustand (optional)
CSS-in-JS: Emotion (optional)
Icons: SVG (18+ built-in)
```

### Component Structure
```
Primitives (5)          Core reusable components
└── Buttons, Cards, Icons, Sections, Containers

Components (8)          Feature-specific components
└── Header, Hero, Services, Features, Stats, Carousel, CTA, Footer

Pages (1)               Complete page assembly
└── HomePage with Modal, Navigation, All Sections

Design System (1)       Centralized design tokens
└── 200+ design variables, animations, easing curves
```

## 🎬 Animation Specifications

### Timing
- **Fast**: 150ms (feedback)
- **Small**: 220ms (micro-interactions)
- **Base**: 420ms (standard)
- **Slow**: 600ms (entrance)

### Easing Curves
- **Spring** (primary): `cubic-bezier(0.22, 1, 0.36, 1)`
- **Linear, EaseIn, EaseOut, Bounce, BackOut**: Available

### Effects
- Parallax hero background
- Staggered children (80ms)
- Icon animations
- Card lift effects
- Carousel transitions
- Counter animations
