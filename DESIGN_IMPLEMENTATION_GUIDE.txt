================================================================================
USAGE EXAMPLES
================================================================================

CREATING NEW COMPONENTS:

1. Import the Card Component:
   
   import Card from './components/Card';
   
   <Card className="card-primary">
     <div className="card-header">
       <div className="card-header-content">
         <h2 className="card-title">Title</h2>
       </div>
     </div>
     <div className="card-content">
       Your content here
     </div>
   </Card>

2. Using Buttons:
   
   <button className="btn btn-primary">Save</button>
   <button className="btn btn-secondary">Cancel</button>
   <button className="btn btn-success btn-large">Submit</button>
   <button className="btn btn-danger btn-small">Delete</button>

3. Form Inputs:
   
   <input 
     type="text" 
     className="form-control" 
     placeholder="Enter name"
   />
   
   <select className="form-control">
     <option>Select option</option>
   </select>

4. Layout with Spacing:
   
   <div className="container">
     <div className="row">
       <div className="col-lg-6 mb-4">
         <Card>Content</Card>
       </div>
       <div className="col-lg-6 mb-4">
         <Card>Content</Card>
       </div>
     </div>
   </div>

5. Grid System (Bootstrap):
   
   .col-md-3     → 25% width (3 columns of 12)
   .col-md-4     → 33.33% width (4 columns)
   .col-md-6     → 50% width (2 columns)
   .col-lg-3     → 25% width on large screens
   .col-12       → 100% width (full width)

================================================================================
RESPONSIVE DESIGN PATTERNS
================================================================================

Mobile-First Approach:
  1. Design for mobile (< 768px) first
  2. Add breakpoints for tablet (768px - 991px)
  3. Optimize for desktop (992px+)

Breakpoints:
  
  Mobile:       < 768px    (default)
  Tablet:       768px      (md breakpoint)
  Desktop:      992px      (lg breakpoint)
  Large:        1200px+    (xl breakpoint)

Example Responsive Grid:

  <div className="row">
    <div className="col-12 col-md-6 col-lg-4">
      Full width on mobile
      50% on tablet
      33% on desktop
    </div>
  </div>

Text Scaling:

  Mobile:   h1 = 2rem, h2 = 1.5rem, h3 = 1.25rem
  Tablet:   h1 = 2rem, h2 = 1.75rem, h3 = 1.5rem
  Desktop:  h1 = 2.5rem, h2 = 2rem, h3 = 1.5rem

ACCESSIBILITY GUIDELINES
================================================================================

Color Contrast:
  ✓ Primary (#3b5d50) on White: 8.5:1 ratio (AAA)
  ✓ Secondary (#f9bf29) on White: 4.2:1 ratio (AA)
  ✓ Dark (#2f2f2f) on White: 13:1 ratio (AAA)
  ✓ Text Gray (#6a6a6a) on White: 5.5:1 ratio (AA)

Keyboard Navigation:
  ✓ All interactive elements keyboard accessible
  ✓ Focus states clearly visible
  ✓ Tab order logical and intuitive
  ✓ No keyboard traps

Focus Indicators:
  outline: 2px solid var(--primary-color)
  outline-offset: 2px

ARIA Labels:
  Always use semantic HTML
  Add aria-label for icon-only buttons
  Use proper heading hierarchy (h1, h2, h3...)

================================================================================
ANIMATION GUIDELINES
================================================================================

Button Hover:
  Transform: translateY(-2px)
  Duration: 0.3s
  Easing: ease

Card Hover:
  Transform: translateY(-5px)
  Duration: 0.3s
  Easing: ease

Link Underline:
  Width: 0 → 100%
  Duration: 0.15s
  Easing: ease-out

Navigation Icons:
  Scale: 1 → 1.1
  Duration: 0.3s
  Easing: ease

Keep animations subtle and purposeful:
  ✓ Don't over-animate
  ✓ Use consistent timing
  ✓ Respect prefers-reduced-motion
  ✓ Animations should enhance, not distract

================================================================================
CUSTOMIZATION EXAMPLES
================================================================================

1. Change Primary Color:
   
   In App.css, :root selector:
   --primary-color: #0066cc;
   
   Updates: Buttons, cards, links, focus states automatically

2. Adjust Spacing:
   
   --spacing-md: 1.25rem;  (was 1rem)
   
   Affects: Padding, margins, gaps throughout

3. Modify Button Style:
   
   .btn-primary {
     border-radius: 8px;        (less rounded)
     padding: 14px 28px;        (taller button)
     font-weight: 700;          (bolder text)
   }

4. Card Styling:
   
   .card {
     border-radius: 15px;       (less rounded)
     box-shadow: 0 0 0;         (no shadow)
     border: 2px solid;         (thicker border)
   }

5. Typography:
   
   h1 {
     font-size: 3rem;           (bigger headers)
     letter-spacing: -0.05em;   (tighter text)
   }
